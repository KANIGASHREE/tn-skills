# PocketSmart AI

PocketSmart AI is a smart budget planning application built using:

- FastAPI
- Python
- SQLite
- SQLAlchemy
- JWT Authentication
- Jinja2
- JavaScript
- HTML/CSS
- Gemini Generative AI
- Local fallback recommendation engine

The application contains three major planners:

1. Home Interior Planner
2. Party Budget Planner
3. Jewelry Planner

## Features

- User registration
- Login
- JWT authentication
- Dashboard
- Home planning
- Party planning
- Jewelry planning
- Outfit image upload
- Gemini AI integration
- Budget-aware recommendations
- Recommendation history
- Marketplace search links
- REST APIs
- Swagger API documentation
- Automated tests
